### Remaining findings

1. **Medium — lookup short-circuit regression is not pinned.**
   Replacing the correct non-short-circuiting `|=` with
   `addressed = addressed || ownDidSubjects.Contains(toSubject)` would pass both new tests:
   every `to` entry is still parsed, while `2 <= 3` still satisfies the lookup assertion.
   Required correction: assert lookup-count equality, preferably across first/middle/last/miss.
2. **Medium — residual timing language overclaims.**
   Equal operation counts remove the coarse match-position/work-count channel, but ordinary
   `FrozenSet` and string comparisons are data-dependent. Repeating one guessed DID throughout
   the bounded `to` list can amplify hit/miss path differences. Documentation must not conclude
   that membership timing is impossible.
3. **Review hygiene — live PR description is stale.**
   It still presents the superseded algorithm, the false "both sizes known" premise, the
   withdrawn "no oracle" claim, old timing figures, the prior test count, and an unfiled
   observer follow-up.
4. **Low — documentation contradictions.**
   All-invalid wire `to` entries do yield `NotAddressed`, contrary to the "cannot manufacture a
   warning" sentence; invalid configured identifiers are rejected at construction, not skipped.

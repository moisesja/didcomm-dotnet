## Design

`InboundObservation.FromUnpackResult` must preserve three distinct states:

1. **Verified snapshot covers current content:** source all six positional trust
   members, all three key bindings, and `RecipientAddressing` from the snapshot.
2. **Verified snapshot exists but current content diverged:** fail closed with
   `Encrypted = false`, `Authenticated = false`, `NonRepudiation = false`,
   `AnonymousSender = false`, null sender/signer kids, null bindings, and
   `RecipientAddressing.NotEvaluated`.
3. **No verified snapshot ever existed:** preserve compatibility by copying only
   the six positional trust members from the caller-supplied synthetic result;
   bindings remain null and addressing remains `NotEvaluated`.

The implementation will retain both `hasVerifiedSnapshot` and
`snapshotCoversContent` rather than collapsing divergence into the same null
state used for synthetic results. No public signature or new type is needed.

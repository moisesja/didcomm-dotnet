# GA 1.0.0 release + NuGet rebrand to `DidCommDotNet`

**Goal:** Ship the first GA (stable, non-prerelease) release as `v1.0.0`, with the NuGet
package IDs rebranded to the `DidCommDotNet` brand.

## Decisions (defaults chosen — flag if you want different)

1. **Rename depth = PackageId only.** Change only `<PackageId>` in each csproj. Assembly
   names (`DidComm.Core.dll`) and C# namespaces (`using DidComm;`) stay unchanged → **zero
   source-breaking churn**, no `.cs` edits. (Package ID ≠ assembly name is standard NuGet practice.)
2. **Naming = root + sub-packages** (Polly/Serilog style), most literal reading of "the
   nuget package called DidCommDotNet":

   | Project | Old PackageId | New PackageId |
   |---|---|---|
   | DidComm.Core | `DidComm.Core` | **`DidCommDotNet`** |
   | DidComm.Extensions.DependencyInjection | `DidComm.Extensions.DependencyInjection` | `DidCommDotNet.Extensions.DependencyInjection` |
   | DidComm.AspNetCore | `DidComm.AspNetCore` | `DidCommDotNet.AspNetCore` |
   | DidComm.Transports.Http | `DidComm.Transports.Http` | `DidCommDotNet.Transports.Http` |
   | DidComm.Transports.WebSocket | `DidComm.Transports.WebSocket` | `DidCommDotNet.Transports.WebSocket` |
   | DidComm.Adapters.NetDid | `DidComm.Adapters.NetDid` | `DidCommDotNet.Adapters.NetDid` |

   > One-word alt: make core `DidCommDotNet.Core` for a uniform prefix instead of root `DidCommDotNet`.

   Because all inter-project links are `ProjectReference`, `dotnet pack` auto-emits the new IDs
   as the package-to-package dependencies. No manual dependency edits.
3. **Version = 1.0.0**, non-prerelease. Tag-driven (`v1.0.0` → `-p:DidCommVersion=1.0.0`).
